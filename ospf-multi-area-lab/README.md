# OSPF Multi-Area Lab (PNETLab)

A hands-on Multi-Area OSPF lab built and verified on PNETLab, by **Mohamed Elafndy**.

The topology has 8 routers across 5 areas. R1 is the ASBR and redistributes four static routes into OSPF as type E1. The lab covers stub and totally stubby areas, MD5 and clear-text authentication, passive interfaces, and a virtual link.

## Topology

| Area | Network | Routers | Notes |
|------|---------|---------|-------|
| Area 0 | 10.100.1.0/24 | R1, R2, R4, R6 (via switch) | Backbone, MD5 authentication |
| Area 23 | 10.23.1.0/24 | R2 (ABR), R3 | Totally stubby, clear-text authentication |
| Area 45 | 10.45.1.0/24 | R4 (ABR), R5 | Stub |
| Area 67 | 10.67.1.0/24 | R6 (ABR), R7 | Transit area for the virtual link |
| Area 78 | 10.78.1.0/24 | R7 (ABR), R8 | Attached to Area 0 through a virtual link |

External routes redistributed on R1 (static, pointing to Null0): `172.31.0.0/24`, `172.31.1.0/24`, `172.31.2.0/24`, `172.31.3.0/24`.

Router IDs follow the router number (R1 = `1.1.1.1` ... R8 = `8.8.8.8`).

## Lab Requirements

1. Configure basic OSPF using the simplest method available. Redistribute the static routes on R1 as type E1.
2. OSPF must never form neighbor relationships on interfaces where no other OSPF routers exist.
3. All routers in Area 0 use MD5 authentication. Routers in Area 23 support clear-text authentication.
4. Area 45 must not receive external routes and must reach the external network through a default route that is not configured statically.
5. Area 23 must not receive type 3, 4 or 5 LSAs and must reach the external network through a default route with an initial cost of 100.
6. When finished, all routers must be able to ping every route in the OSPF routing table.

## Solution Overview

| Requirement | Implementation |
|-------------|----------------|
| Basic OSPF | `ip ospf 1 area X` under each interface |
| E1 redistribution | `redistribute static metric-type 1 subnets` on R1 |
| No neighbors on empty interfaces | `passive-interface default`, then `no passive-interface` on links with OSPF neighbors |
| MD5 in Area 0 | `area 0 authentication message-digest` and `ip ospf message-digest-key 1 md5 ...` |
| Clear text in Area 23 | `area 23 authentication` and `ip ospf authentication-key ...` on R2 and R3 |
| Area 45 | `area 45 stub` on R4 and R5 (default route is generated by the ABR) |
| Area 23 | `area 23 stub` on R3, `area 23 stub no-summary` and `area 23 default-cost 100` on R2 |
| Area 78 connectivity | Virtual link between R6 and R7 across Area 67 |

### Virtual link

Area 78 is not directly attached to Area 0. Without a virtual link, R8 formed a FULL adjacency with R7 but received no type 3 or type 4 LSAs, so its routing table stayed empty. A virtual link between R6 and R7 across Area 67 fixed it:

```
! R6
router ospf 1
 area 67 virtual-link 7.7.7.7 message-digest-key 1 md5 cisco123

! R7
router ospf 1
 area 67 virtual-link 6.6.6.6 message-digest-key 1 md5 cisco123
```

R7 also needs `area 0 authentication message-digest`, because the virtual link belongs to Area 0 and uses its authentication type.

## Verification

After the configuration:

- R3 has a single default route `O*IA 0.0.0.0/0` with cost 164 (100 default cost + 64 link cost).
- R5 has a default route and inter-area routes, and no E1 routes.
- R2, R4, R6, R7 and R8 learn the 172.31.x.x networks as `O E1`.
- Ping tests from every router to all OSPF interface addresses succeed 100% (5/5).

Commands used:

```
show ip ospf neighbor
show ip route ospf
show ip ospf interface brief
show ip protocols
show ip ospf database
show ip ospf virtual-links
```

Ping test script (run inside `tclsh` on each router):

```
foreach address {10.100.1.1 10.100.1.2 10.100.1.4 10.100.1.6 10.23.1.2 10.23.1.3 10.45.1.4 10.45.1.5 10.67.1.6 10.67.1.7 10.78.1.7 10.78.1.8} { ping $address }
```

## How to Use

1. In PNETLab, import `topology/ospf-lab.zip` (Main page, Import).
2. Start all nodes.
3. Paste the matching file from `configs/` on each router, or open the lab if the configs were exported with it.
4. Run the verification commands above.
